# -App-Store-Analysis-PowerBI
This project presents an interactive **Apple App Store Analysis Dashboard** built using **Microsoft Power BI**.   The dashboard provides deep insights into app distribution, user ratings, pricing trends, developer portfolios, and app update patterns across multiple years.
## 📈 Dashboard Pages Overview

### 1️⃣ App Store Overview
- Total apps, reviews, developers, pricing & size metrics
- User ratings by genre
- Free vs Paid apps comparison
- Apps released over years
- Genre-wise app distribution

### 2️⃣ Developer Analysis
- Top developers by number of apps
- Developer content rating distribution
- Price vs Rating relationship
- Developer portfolio performance
- App concentration by developers

### 3️⃣ App Details
- Earliest app release tracking
- App update trends over years
- Average app size & price growth
- App-wise portfolio table
## 🔍 Key Insights
- Free apps dominate the App Store (~91%)
- Business and Education are the most popular genres
- App releases peaked around 2014–2016
- Higher app price does not guarantee better user ratings
- A few developers own a large portion of apps
